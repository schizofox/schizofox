# Schizofox

Schizofox provides declarative, privacy-hardened Firefox ESR configurations for
NixOS and Home Manager.

## Module options

The complete `programs.schizofox` option reference is generated from the module
source during the documentation build. It covers the same public configuration
surface for both module adapters.

## Installation

Import either `nixosModules.schizofox` or `homeManagerModules.schizofox` from
the flake, then enable `programs.schizofox` in the corresponding configuration.
